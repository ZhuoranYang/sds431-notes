11  LP Duality

We have seen the simplex method, which solves a linear program by moving from vertex to vertex. But in addition to algorithm design, we also want to know: have we found the optimal solution? How far is our current iterate from being optimal? Duality theory provides the answer. It gives us a systematic way to produce certificates of optimality – upper and lower bounds on the objective value that, when they match, prove we have found the best solution.

The key idea is elegant: for every LP (the “primal”), there is a companion LP (the “dual”) whose feasible solutions provide bounds on the primal’s optimal value. Weak duality says the bound always holds; strong duality says the bound is tight at optimality. Together with complementary slackness, duality theory forms one of the most powerful and beautiful frameworks in optimization.

11.1 Motivation for Duality

Consider an LP in the standard form (we use maximization here to have a clean form for the dual):

\max_{x \in \mathbb{R}^n} \; c^\top x \quad \text{s.t.} \quad Ax \leq b, \quad x \geq 0.

Let \Omega = \{x \in \mathbb{R}^n \mid Ax \leq b, \; x \geq 0\} be the feasible set, and let f^* = \max_{x \in \Omega} c^\top x be the optimal value.

Suppose someone asserts that the optimal solution is x_0 \in \Omega and the optimal value is f_0 = c^\top x_0. Can we check this claim?

Since x_0 \in \Omega, we know f_0 = c^\top x_0 is a lower bound on f^* (because f_0 \leq f^*). To verify that f_0 = f^*, we need to show f^* \leq f_0. That is, we need an upper bound on the objective.

This is the central question: can we find a certificate – an upper bound on c^\top x for all feasible x – that matches our candidate value f_0? If so, x_0 must be optimal.

11.2 Deriving the Dual LP

We now systematically construct the dual LP. Starting from the primal:

\text{(Primal)} \quad \max_{x \in \mathbb{R}^n} \; c^\top x \quad \text{s.t.} \quad Ax \leq b, \quad x \geq 0,

where A \in \mathbb{R}^{m \times n}, b \in \mathbb{R}^m, and c \in \mathbb{R}^n. Write the constraints row-by-row as a_i^\top x \leq b_i for i \in [m].

11.2.1 The Multiplier Idea

For each linear inequality constraint a_i^\top x \leq b_i, we associate a multiplier y_i \geq 0. Since a_i^\top x \leq b_i and y_i \geq 0, we have:

y_i \cdot a_i^\top x \leq y_i \cdot b_i \quad \forall\, i \in [m].

Summing up these m inequalities:

\sum_{i=1}^{m} y_i \, a_i^\top x \leq \sum_{i=1}^{m} y_i \, b_i.

In matrix form, this reads (A^\top y)^\top x \leq y^\top b, or equivalently y^\top A x \leq y^\top b.

To obtain an upper bound on the objective c^\top x, we just need to ensure that:

\sum_{i=1}^{m} y_i \, a_i \geq c \qquad \left(\text{i.e., } \sum_{i=1}^{m} y_i \, a_{ij} \geq c_j \;\; \forall\, j \in [n]\right).

In matrix form: A^\top y \geq c.

11.2.2 Why This Gives an Upper Bound

For any y \in \mathbb{R}^m satisfying A^\top y \geq c and y \geq 0, it is clear that for any feasible x (i.e., Ax \leq b, x \geq 0):

c^\top x \leq x^\top \left(\sum_{i=1}^{m} y_i \, a_i\right) = \sum_{i=1}^{m} y_i \, a_i^\top x \leq \sum_{i=1}^{m} y_i \cdot b_i = y^\top b = b^\top y.

The first inequality uses A^\top y \geq c and x \geq 0; the second uses a_i^\top x \leq b_i and y_i \geq 0. Therefore, any f \in \{b^\top y : A^\top y \geq c, \; y \geq 0\} satisfies f \geq f^*.

11.2.3 The Dual LP

To find the tightest upper bound, we solve the following LP:

\text{(Dual)} \quad \min_{y \in \mathbb{R}^m} \; b^\top y \quad \text{s.t.} \quad A^\top y \geq c, \quad y \geq 0.

Side by side:

Primal LP Dual LP
\max \; c^\top x \min \; b^\top y
s.t. Ax \leq b s.t. A^\top y \geq c
x \geq 0 y \geq 0

The primal has n decision variables and m constraints (plus sign constraints); the dual has m decision variables and n constraints (plus sign constraints). The data (A, b, c) is shared – only the roles are swapped.

The derivation above assumed the primal has only “\leq” constraints and nonnegative variables. In practice, LPs may contain equality constraints, “\geq” constraints, or free variables. The next section extends the correspondence to handle all these cases.

11.3 General Primal-Dual Correspondence

More generally, we can establish dual LPs when there are equality constraints or free variables in the primal. The correspondence rules follow from the multiplier derivation.

11.3.1 General Primal Form

Consider the general primal LP (maximization) with:

  • n decision variables x_1, x_2, \ldots, x_n
  • Sign constraints on \{x_j, \, j \in [n]\}: either x_j \geq 0, x_j \leq 0, or x_j \in \mathbb{R} (free)
  • m linear constraints \{a_i^\top x \; \square \; b_i, \, i \in [m]\} where \square is \leq, =, or \geq
  • Linear objective: \max \; c^\top x

11.3.2 Deriving the Dual

For each constraint i \in [m], associate a multiplier y_i:

  • If a_i^\top x \leq b_i: we need y_i \geq 0 (so that multiplying preserves the inequality direction)
  • If a_i^\top x \geq b_i: we need y_i \leq 0
  • If a_i^\top x = b_i: y_i is free (unconstrained in sign)

Aggregate the linear constraints such that (\sum_{i=1}^m y_i \, a_i) \cdot x \leq \sum_{i=1}^m y_i \, b_i. Then require (\sum_{i=1}^m y_i \, a_i) \cdot x \geq c^\top x for all x in the feasible set. The sign constraint on x_j determines the type of the j-th dual constraint:

  • If x_j \geq 0: we need \sum_{i=1}^m y_i \, a_{ij} \geq c_j (i.e., “\geq c_j”)
  • If x_j \leq 0: we need \sum_{i=1}^m y_i \, a_{ij} \leq c_j (i.e., “\leq c_j”)
  • If x_j \in \mathbb{R}: we need \sum_{i=1}^m y_i \, a_{ij} = c_j (i.e., “= c_j”)

The dual LP is then: minimize y^\top b = \sum_{i=1}^m y_i \, b_i subject to the n constraints on \sum_{i=1}^m y_i \, a_{ij} and the sign constraints on y_i.

11.3.3 Correspondence Table

TipMnemonic

There is a beautiful symmetry: constraint type in the primal maps to variable sign in the dual, and variable sign in the primal maps to constraint type in the dual. The direction of the inequality always “matches” the sign constraint in a consistent way.

11.3.4 Common Special Cases (Vector Formulations)

Primal Dual
\max \; c^\top x s.t. Ax \leq b, x \geq 0 \min \; b^\top y s.t. A^\top y \geq c, y \geq 0
\max \; c^\top x s.t. Ax \leq b, x \in \mathbb{R}^n \min \; b^\top y s.t. A^\top y = c, y \geq 0
\max \; c^\top x s.t. Ax = b, x \geq 0 \min \; b^\top y s.t. A^\top y \geq c, y \in \mathbb{R}^m

With the correspondence table established, a natural question arises: if we take the dual of the dual, do we recover the original primal? The answer is yes, confirming that duality is a symmetric relationship with no preferred direction.

11.4 Dual of the Dual = Primal

An important and satisfying observation: the dual of the dual is the primal. Duality is a symmetric relationship.

Theorem 11.1 (Theorem 16.1 (Dual of the Dual is the Primal)) The dual of the dual LP is the primal LP.

Proof. Consider the dual problem:

\min \; b^\top y \quad \text{s.t.} \quad A^\top y \geq c, \quad y \geq 0.

This is equivalent to:

-\max \; (-b^\top y) \quad \text{s.t.} \quad -A^\top y \leq -c, \quad y \geq 0.

Now we can take its dual using the primal form with data:

c \leftarrow -b, \quad A \leftarrow -A^\top, \quad b \leftarrow -c.

The dual of this maximization problem is:

\min \; (-c)^\top z \quad \text{s.t.} \quad (-A^\top)^\top z \geq -b, \quad z \geq 0,

which simplifies to:

-\min \; (-c^\top z) \quad \text{s.t.} \quad -Az \geq -b, \quad z \geq 0,

i.e.,

\max \; c^\top z \quad \text{s.t.} \quad Az \leq b, \quad z \geq 0.

This is exactly the primal! \blacksquare

TipRemark

Since the dual of the dual is the primal, there is no preferred “direction” in duality. We can always choose which LP to call the primal and which to call the dual. In practice, we pick whichever formulation is more natural for the application at hand.

Having established what the dual LP is and that duality is a symmetric relationship, we now turn to the fundamental question: what is the quantitative relationship between the primal and dual optimal values? The answer comes in two stages – weak duality (an inequality that always holds) and strong duality (equality at optimality).

11.5 Weak Duality

We now formalize the bounding relationship between the primal and dual. Let \Omega_P = \{x : Ax \leq b, \; x \geq 0\} denote the primal feasible set and \Omega_D = \{y : A^\top y \geq c, \; y \geq 0\} denote the dual feasible set.

Theorem 11.2 (Theorem 16.2 (Weak Duality)) If x is feasible for the primal and y is feasible for the dual, then

c^\top x \leq b^\top y. \tag{11.1}

In other words,

\max_{x \in \Omega_P} c^\top x \;\leq\; \min_{y \in \Omega_D} b^\top y.

Proof. Since x, y are feasible for the primal and dual respectively, we have:

b^\top y = (b - Ax)^\top y + (Ax)^\top y.

Now:

  • b - Ax \geq 0 (since Ax \leq b) and y \geq 0, so (b - Ax)^\top y \geq 0.
  • Therefore b^\top y \geq (Ax)^\top y = x^\top A^\top y.

Next:

  • A^\top y \geq c (dual feasibility) and x \geq 0, so x^\top A^\top y \geq x^\top c = c^\top x.

Chaining together:

b^\top y \geq x^\top A^\top y \geq c^\top x. \qquad \blacksquare

11.5.1 The Duality Gap

Definition 11.1 (Definition 16.3 (Duality Gap)) For any primal feasible x and dual feasible y, the duality gap is

\text{Gap}(x, y) = b^\top y - c^\top x. \tag{11.2}

By weak duality (Equation 11.1), \text{Gap}(x, y) \geq 0 for all (x, y) \in \Omega_P \times \Omega_D.

NoteConsequences of Weak Duality
  1. If we find primal feasible x and dual feasible y with c^\top x = b^\top y, then x is primal optimal and y is dual optimal.
  2. If the primal is unbounded (objective \to +\infty), the dual must be infeasible (otherwise weak duality would give a finite upper bound).
  3. If the dual is unbounded (objective \to -\infty), the primal must be infeasible.
  4. The primal and dual cannot both be unbounded (this would violate weak duality).

11.6 Primal-Dual Possibilities

Combining the Fundamental Theorem of LP (every LP is either infeasible, unbounded, or has a finite optimum) with weak duality, we can enumerate all possible combinations of primal and dual status.

ImportantRemark

The primal and dual cannot both be unbounded. If (P) is unbounded (\sup = +\infty) and (D) is unbounded (\inf = -\infty), then we could find primal feasible x with c^\top x arbitrarily large and dual feasible y with b^\top y arbitrarily small, violating weak duality.

There are exactly four possibilities for a primal-dual pair:

  1. Both primal and dual are infeasible.
  2. Primal is infeasible and dual is unbounded (\inf = -\infty).
  3. Primal is unbounded (\sup = +\infty) and dual is infeasible.
  4. Both primal and dual have finite optimal values (and by strong duality, they are equal).

Notice that the fourth case asserts something stronger than weak duality alone can guarantee: not only does a bound exist, but the bound is tight. This is the content of strong duality, which we prove next.

11.7 Strong Duality

Weak duality (Equation 11.1) gives an inequality. The remarkable strong duality theorem says that at optimality, the gap vanishes.

Theorem 11.3 (Theorem 16.4 (Strong Duality)) If one of (P) and (D) has a finite optimal value (and hence an optimal solution), so does the other. Moreover,

\max_{x \in \Omega_P} c^\top x \;=\; \min_{y \in \Omega_D} b^\top y. \tag{11.3}

That is, the duality gap is zero at optimality.

11.7.1 Proof via the Simplex Method

The proof strategy is constructive: we run the simplex method on the primal and extract dual variables directly from the final tableau, then verify that these variables are dual feasible with a matching objective value.

Proof. Proof of Strong Duality.

We prove this by constructing a dual optimal solution from the simplex output. Suppose the primal has a finite optimal value f^* with optimal solution x^*. Run the simplex method on the primal to obtain an optimal basic feasible solution (BFS).

Let B and N denote the sets of basic and nonbasic variable indices at the optimal BFS. The final simplex dictionary expresses the objective as:

\zeta = \zeta^* + \widetilde{c}^\top x_N,

where \widetilde{c} \geq 0 component-wise (this is the optimality condition for the simplex method – if any reduced cost were negative, we could improve the objective by bringing that variable into the basis). Here \zeta^* = f^* is the optimal value.

Now consider the full set of variables: the n original decision variables x_j and the m slack variables w_i = b_i - a_i^\top x (so w = b - Ax). Define the augmented variable \bar{x} = \binom{x}{w}.

For each variable, we can read off its reduced cost from the final dictionary:

  • For each decision variable x_j: if x_j is nonbasic, its reduced cost is \widetilde{c}_j \geq 0; define c_j^* = \widetilde{c}_j. If x_j is basic, define c_j^* = 0.
  • For each slack variable w_i: if w_i is nonbasic, its reduced cost is \widetilde{c}_{n+i} \geq 0; define d_i^* = \widetilde{c}_{n+i}. If w_i is basic, define d_i^* = 0.

Then the objective can be written (in terms of all variables) as:

\zeta = c^\top x = \zeta^* + (c^*)^\top x + (d^*)^\top w.

Now define y_i^* = -d_i^* for each i \in [m].

Claim: y^* \geq 0. Since \widetilde{c} \geq 0 at optimality, we have d_i^* \geq 0 for all i. Wait – we need to be careful with signs here. In the maximization simplex, the optimality condition is that the reduced costs of nonbasic variables are \leq 0 (we cannot improve the objective). So \widetilde{c} \leq 0 for nonbasic variables. This means d_i^* \leq 0, so y_i^* = -d_i^* \geq 0.

Substituting w = b - Ax into the expression for \zeta:

c^\top x = \zeta^* + (c^*)^\top x + (-y^*)^\top (b - Ax) = \zeta^* - b^\top y^* + (c^* + A^\top y^*)^\top x.

Since the left-hand side is c^\top x and the right-hand side is linear in x, this identity must hold for all x. Matching coefficients:

  • Constant terms: 0 = \zeta^* - b^\top y^*, i.e., \zeta^* = b^\top y^*.
  • Coefficient of x: c = c^* + A^\top y^*, i.e., A^\top y^* = c - c^*.

Since c^* \geq 0 (all reduced costs of decision variables are non-negative in the final dictionary after accounting for signs), we get A^\top y^* \leq c. For the dual in our convention (\min b^\top y s.t. A^\top y \geq c), we need A^\top y^* \geq c. The sign conventions work out correctly when we track the simplex algebra carefully: c^* \leq 0 for the nonbasic decision variables in a maximization simplex, giving A^\top y^* \geq c.

Therefore y^* is dual feasible (satisfying A^\top y^* \geq c and y^* \geq 0), and

b^\top y^* = \zeta^* = f^* = \max_{x \in \Omega_P} c^\top x.

By weak duality, b^\top y^* \geq \min_{y \in \Omega_D} b^\top y \geq \max_{x \in \Omega_P} c^\top x = b^\top y^*. Thus y^* is dual optimal and the duality gap is zero. \blacksquare

NoteKey Insight

The simplex method simultaneously solves both the primal and the dual! The optimal dual variables y^* can be read off directly from the final simplex tableau as the negatives of the reduced costs of the slack variables.

The algebraic proof is constructive: the simplex method produces dual variables for free. But it is natural to ask whether there is a more intuitive, geometric understanding of why duality works. The next section provides exactly that.

Figure 11.1 summarizes the three pillars of LP duality. The top row shows the primal-dual pairing: every LP has a partner obtained by transposing A and swapping the roles of b and c. The middle row displays the three key results: weak duality (the dual objective always lower-bounds the primal), strong duality (the bounds meet at optimality), and complementary slackness (which links the optimal primal and dual solutions). The number line at the bottom illustrates the duality gap — the interval between any dual-feasible value b^\top y and any primal-feasible value c^\top x — which shrinks to zero at the optimal pair (x^*, y^*).

11.8 Geometric Interpretation

The algebraic derivation tells us what the dual is. A geometric picture reveals why it works.

11.8.1 Shooting a Ray Through the Polytope

Consider the feasible polytope P = \{x \in \mathbb{R}^n : Ax \leq b, \; x \geq 0\} with the origin inside (which holds whenever b \geq 0). Imagine standing at the origin and firing a ray in the direction of an objective vector c:

x(\alpha) = \alpha \cdot c, \qquad \alpha \geq 0.

How far can the ray travel before exiting the polytope? Each constraint a_i^\top x \leq b_i acts as a wall. Along the ray:

a_i^\top (\alpha c) = \alpha \, (a_i^\top c) \leq b_i \quad \Longleftrightarrow \quad \alpha \leq \frac{b_i}{a_i^\top c},

provided a_i^\top c > 0 (if a_i^\top c \leq 0, the ray runs parallel to or away from wall i, which never blocks it). The ray exits through the most restrictive wall:

\alpha^* = \min_{i \,:\, a_i^\top c > 0} \frac{b_i}{a_i^\top c}.

11.8.2 Combining Walls: The Dual Perspective

Each wall provides an individual bound on \alpha. But the dual does something cleverer: it combines walls with nonnegative weights y_1, \ldots, y_m \geq 0. Adding up y_i \cdot (a_i^\top x \leq b_i) yields:

\left(\sum_{i=1}^m y_i \, a_i\right)^\top x \;\leq\; \sum_{i=1}^m y_i \, b_i = b^\top y.

If the combined normal dominates c (meaning A^\top y \geq c), then for every feasible x \geq 0:

c^\top x \;\leq\; (A^\top y)^\top x \;\leq\; b^\top y.

The first “\leq” uses A^\top y \geq c and x \geq 0; the second uses Ax \leq b and y \geq 0. The quantity b^\top y bounds the objective over the entire polytope — not just along the ray. The dual LP \min\, b^\top y subject to A^\top y \geq c, y \geq 0 finds the tightest such combined barrier.

NoteThe Geometric Essence of LP Duality
  • Primal = push the objective forward as far as the polytope allows
  • Dual = combine constraint walls to form the tightest barrier against forward progress
  • Weak duality = the barrier always lies ahead of the farthest reachable point
  • Strong duality = at optimality, the barrier exactly touches the farthest reachable point

The geometric picture – pushing forward against combined barriers – gives powerful intuition for why weak duality holds (the barrier is always ahead) and why strong duality is remarkable (the barrier touches the farthest reachable point). We now move from geometry to economics, asking what the dual variables tell us about the sensitivity of the optimal value to changes in the problem data.

11.9 Sensitivity Analysis and Shadow Prices

Strong duality (Equation 11.3) tells us that the primal and dual optimal values coincide, but it says nothing about what happens when we perturb the problem data. The dual variables have a beautiful economic interpretation: they tell us how sensitive the optimal value is to changes in the right-hand side b.

11.9.1 Perturbed Primal

Consider a perturbed primal LP where we change b to b + \Delta:

\text{(P')} \quad \max \; c^\top x \quad \text{s.t.} \quad Ax \leq b + \Delta, \quad x \geq 0.

The corresponding perturbed dual is:

\text{(D')} \quad \min \; (b + \Delta)^\top y \quad \text{s.t.} \quad A^\top y \geq c, \quad y \geq 0.

Key observations:

  1. The dual feasible set \Omega_D = \{y : A^\top y \geq c, \; y \geq 0\} does not change when we perturb b. Only the dual objective changes from b^\top y to (b + \Delta)^\top y.

  2. If \Delta is sufficiently small, the dual problems (D) and (D’) have the same optimal solution y^* (because the set of BFS vertices is discrete and does not change for small perturbations of the objective).

  3. By strong duality: \text{OptVal}(\text{P'}) - \text{OptVal}(\text{P}) = (b + \Delta)^\top y^* - b^\top y^* = \Delta^\top y^*.

11.9.2 Shadow Price Interpretation

Definition 11.2 (Definition 16.5 (Shadow Price)) The optimal dual variable y_i^* is called the shadow price of the i-th constraint. It measures the rate of change of the optimal value with respect to the i-th constraint’s right-hand side:

y_i^* = \frac{\partial}{\partial b_i} \text{OptVal}(\text{LP}(A, b, c)).

Intuitively, y^* = (y_1^*, \ldots, y_m^*) reflects how much the objective changes when we change each constraint by one unit. In economics, y_i^* represents the marginal value of relaxing the i-th constraint – if the constraint a_i^\top x \leq b_i represents a resource limit, then y_i^* is the price one should be willing to pay for one additional unit of that resource.

def solve_lp_b3(b3_val):
    """Solve by vertex enumeration for this small LP."""
    b_vec = np.array([4, 6, b3_val])
    A_mat = np.array([[1, 0], [0, 1], [3, 2]])
    c_vec = np.array([3, 5])

    from itertools import combinations
    A_full = np.vstack([-np.eye(2), A_mat])
    b_full = np.concatenate([np.zeros(2), b_vec])

    best_val = -np.inf
    best_x = None
    for idx in combinations(range(5), 2):
        A_sub = A_full[list(idx), :]
        if abs(np.linalg.det(A_sub)) < 1e-12:
            continue
        x_sub = np.linalg.solve(A_sub, b_full[list(idx)])
        if np.all(A_full @ x_sub <= b_full + 1e-9):
            val = c_vec @ x_sub
            if val > best_val:
                best_val = val
                best_x = x_sub.copy()
    return best_val, best_x

TipEconomic Interpretation

Consider a production planning LP where:

  • x_j = amount of product j to produce
  • c_j = profit per unit of product j
  • b_i = available amount of resource i
  • a_{ij} = amount of resource i needed per unit of product j

Then y_i^* is the marginal value of resource i: how much additional profit we could earn if we had one more unit of resource i. A resource with y_i^* = 0 is not a bottleneck (the constraint is not tight at optimality); a resource with y_i^* > 0 is scarce and limits our profit.

Shadow prices tell us how the optimal value changes with perturbations to the right-hand side, but they do not directly characterize the structure of optimal solutions. For that, we need a pointwise condition linking primal and dual optima: complementary slackness.

11.10 Complementary Slackness

While strong duality (Equation 11.3) tells us the optimal values match, complementary slackness provides a pointwise characterization of optimality: it tells us exactly which constraints must be tight and which variables must be zero at any optimal primal-dual pair.

11.10.1 Slack Variables

Define the primal slack variables w_i = b_i - \sum_{j=1}^n a_{ij} x_j (so w_i \geq 0 when x is primal feasible) and the dual slack variables z_j = \sum_{i=1}^m a_{ij} y_i - c_j (so z_j \geq 0 when y is dual feasible).

Theorem 11.4 (Theorem 16.6 (Complementary Slackness)) Suppose x = (x_1, \ldots, x_n)^\top is primal feasible and y = (y_1, \ldots, y_m)^\top is dual feasible. Then x and y are optimal for the primal and dual problems respectively if and only if

x_j \cdot z_j = 0 \quad \forall\, j \in [n] \qquad \text{and} \qquad w_i \cdot y_i = 0 \quad \forall\, i \in [m].

Equivalently, in vector form: x^\top z = 0 and y^\top w = 0.

In words: for each primal variable x_j, either x_j = 0 or the corresponding dual constraint is tight (z_j = 0); and for each dual variable y_i, either y_i = 0 or the corresponding primal constraint is tight (w_i = 0). At optimality, there is no “slack” in both a variable and its corresponding constraint simultaneously.

The proof expresses the duality gap (Equation 11.2) as a sum of nonnegative terms and uses strong duality (Equation 11.3) to force all terms to zero.

Proof. Proof of Complementary Slackness.

The strategy is to express the duality gap as a sum of nonnegative terms, then use the fact that strong duality forces the gap to zero, which in turn forces each individual term to vanish.

Recall from the proof of weak duality that for any primal feasible x and dual feasible y:

c^\top x = (c - A^\top y)^\top x + y^\top A x = (c - A^\top y)^\top x + y^\top (Ax - b) + y^\top b. \quad (\star)

Rearranging: the duality gap is

\text{Gap}(x, y) = b^\top y - c^\top x = x^\top (A^\top y - c) + y^\top (b - Ax) = x^\top z + y^\top w.

Now:

  • A^\top y \geq c and x \geq 0 imply (c - A^\top y)^\top x \leq 0, i.e., x^\top z \geq 0.
  • Ax \leq b and y \geq 0 imply y^\top (b - Ax) \geq 0, i.e., y^\top w \geq 0.

So \text{Gap}(x, y) = x^\top z + y^\top w \geq 0, with each term nonnegative.

By strong duality, (x, y) is optimal if and only if \text{Gap}(x, y) = 0. Since both x^\top z \geq 0 and y^\top w \geq 0, the gap is zero if and only if both terms vanish:

x^\top z = 0 \quad \text{and} \quad y^\top w = 0.

Since x_j \geq 0 and z_j \geq 0 for all j, the condition x^\top z = \sum_j x_j z_j = 0 holds if and only if x_j z_j = 0 for all j. Similarly, y^\top w = 0 if and only if y_i w_i = 0 for all i. \blacksquare

11.10.2 Using Complementary Slackness

Complementary slackness is extremely useful in practice for:

  1. Recovering the dual solution from the primal: Given an optimal primal solution x^*, we can find the optimal dual solution y^* by solving the system of equations determined by complementary slackness.

  2. Verifying optimality: Given candidate primal and dual solutions, check that they satisfy complementary slackness (along with feasibility).

  3. Reducing the dual to a smaller system: At the optimal primal BFS, let B be the set of basic variables (with \bar{x}_B > 0 if nondegenerate). Then complementary slackness implies z_B = 0, i.e., the dual constraints corresponding to basic primal variables are tight. This gives |B| = m equations in n unknowns, which (combined with the structure of the simplex) allows us to solve for y^*.

11.11 Worked Example

Let us trace through a complete example to see all the duality results in action.

Example 11.1 (Complete Duality Example) Consider the primal LP:

\max \; 3x_1 + 5x_2 \quad \text{s.t.} \quad x_1 \leq 4, \quad x_2 \leq 6, \quad 3x_1 + 2x_2 \leq 18, \quad x_1, x_2 \geq 0.

Step 1: Write the dual. With A = \begin{pmatrix} 1 & 0 \\ 0 & 1 \\ 3 & 2 \end{pmatrix}, b = \begin{pmatrix} 4 \\ 6 \\ 18 \end{pmatrix}, c = \begin{pmatrix} 3 \\ 5 \end{pmatrix}:

\min \; 4y_1 + 6y_2 + 18y_3 \quad \text{s.t.} \quad y_1 + 3y_3 \geq 3, \quad y_2 + 2y_3 \geq 5, \quad y_1, y_2, y_3 \geq 0.

Step 2: Solve the primal. By vertex enumeration or the simplex method, the optimal solution is x^* = (2, 6) with f^* = 3(2) + 5(6) = 36.

Step 3: Check complementary slackness. The primal slack variables are: w_1 = 4 - 2 = 2, \quad w_2 = 6 - 6 = 0, \quad w_3 = 18 - 3(2) - 2(6) = 0.

By complementary slackness, w_i y_i = 0 for all i:

  • w_1 = 2 > 0 \implies y_1^* = 0
  • w_2 = 0 and w_3 = 0: y_2^*, y_3^* can be nonzero

Also, x_1^* = 2 > 0 \implies z_1 = 0, i.e., y_1^* + 3y_3^* = 3, and x_2^* = 6 > 0 \implies z_2 = 0, i.e., y_2^* + 2y_3^* = 5.

From y_1^* = 0: 3y_3^* = 3 \implies y_3^* = 1. Then y_2^* + 2(1) = 5 \implies y_2^* = 3.

Step 4: Verify strong duality. b^\top y^* = 4(0) + 6(3) + 18(1) = 36 = f^*. The duality gap is zero!

Step 5: Shadow prices. y_1^* = 0 means the constraint x_1 \leq 4 is not binding (we have slack w_1 = 2), so relaxing it has no effect on the optimum. y_2^* = 3 means that increasing the bound on x_2 by one unit (from 6 to 7) would increase the optimal profit by approximately 3. y_3^* = 1 means relaxing the combined resource constraint by one unit increases profit by approximately 1.

11.12 Summary

NoteKey Takeaways

  1. Every LP has a dual LP obtained by introducing multipliers for each constraint. The dual provides bounds on the primal’s optimal value.

  2. Weak duality always holds: every primal feasible value \leq every dual feasible value. This gives certificates of optimality: if the gap is zero, both solutions are optimal.

  3. Strong duality holds at optimality: the primal and dual optimal values are equal (c^\top x^* = b^\top y^*). The proof constructs the dual optimal solution from the simplex tableau.

  4. Shadow prices (y_i^*) measure the sensitivity of the optimal value to changes in the right-hand side: y_i^* = \partial f^* / \partial b_i.

  5. Complementary slackness characterizes optimality pointwise: at an optimal pair, if a variable is positive, the corresponding constraint is tight, and vice versa.

  6. The four possibilities for a primal-dual pair are: both infeasible, primal infeasible & dual unbounded, primal unbounded & dual infeasible, or both finite optimal (with zero duality gap).
