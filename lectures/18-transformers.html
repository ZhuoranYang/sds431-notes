18  Transformers

Adapted from slides by Anna Goldie (Stanford CS 224n), John Hewitt, and Song Han (MIT 6.5940)

TipRemark: Prerequisites
  • Part 6: deep generative models, training with gradient descent
  • Part 2: linear algebra, matrix operations

The transformer architecture has fundamentally reshaped artificial intelligence. Since the publication of “Attention Is All You Need” in 2017, transformers have become the universal backbone for language models (GPT, Claude, LLaMA), vision models (ViT), protein structure prediction (AlphaFold), and much more. Understanding how transformers work is now essential for anyone working at the intersection of optimization and machine learning.

At its core, the transformer is built from a small set of mathematical operations — matrix multiplications, softmax normalization, and elementwise nonlinearities — all of which are trained end-to-end using the gradient-based optimization methods developed earlier in this course. The key innovation is the attention mechanism, which allows each token in a sequence to dynamically attend to every other token, computing a weighted average that captures long-range dependencies. Combined with positional encodings, residual connections, and layer normalization, these attention layers are stacked into deep networks with billions of parameters.

This chapter walks through the transformer architecture from the ground up. We will see how token embeddings map discrete words into continuous vectors, how self-attention computes context-dependent representations, and how the full decoder architecture generates text one token at a time. We also analyze the parameter count of GPT-3 to build concrete intuition for the scale of these models.

18.1 What Will Be Covered

  • Language tasks and three types of transformer models (encoder-only, decoder-only, encoder-decoder)
  • Token embedding, positional encoding, and the softmax prediction head
  • The attention mechanism: cross attention and self-attention
  • Multi-head attention, causal masking, MLP layers, residual connections, and layer normalization
  • Full transformer decoder architecture and GPT-3 parameter analysis

18.2 1. Motivation

Transformer models are revolutionary. The foundational paper “Attention Is All You Need” (Vaswani et al., 2017) introduced the Transformer architecture, which has since become the backbone of virtually all modern AI systems: ChatGPT/GPT-4 (OpenAI), Claude (Anthropic), Gemini (Google), LLaMA (Meta), and many more.

Today, Transformer-based models dominate the LMSYS Chatbot Arena Leaderboard (Chiang et al., 2024), with models like GPT-4-Turbo, Claude 3 Opus, and Gemini 1.5 Pro at the top.

Transformers have even shown great promise outside of NLP:

  • Protein folding: AlphaFold2 (Jumper et al., 2021) uses attention mechanisms
  • Image classification: Vision Transformer (ViT) outperforms ResNet-based baselines (Dosovitskiy et al., 2020)
  • ML for Systems: Transformer-based compiler models (GO-one) speed up other Transformer models (Zhou et al., 2020)

18.2.1 Language Tasks

Definition 18.1 (Two Main Types of Language Tasks) 1. Generative tasks (conditional generation): e.g., translation, code generation. \mathbb{P}(\text{text} \mid \text{text / image}).

2. Discriminative tasks (classification): e.g., part-of-speech classification, sentiment analysis. \mathbb{P}(\text{label} \mid \text{text}).

Understanding this distinction between generative and discriminative tasks is important because it directly determines which type of transformer architecture is appropriate: encoder-only models excel at discriminative tasks, while decoder-only models are designed for generation.

18.3 2. Three Types of Transformer-Based Language Models

Depending on the task, transformers come in three flavors that differ in how information flows through the model. The choice between them determines whether the model can “see the whole input at once” (useful for classification) or must generate output one token at a time (necessary for text generation). Understanding these three variants clarifies why modern large language models are almost exclusively decoder-only.

18.3.1 Task Type 1: Encoder-Only (Feature Extraction + Discriminative Tasks)

Definition 18.2 (Encoder-Only Transformer) An encoder-only transformer creates a sequence of token-level features of the input (for discriminative tasks).

  • Input: sequence of tokens w_1, \ldots, w_L; L = sequence length
  • Output: sequence of features z_1, z_2, \ldots, z_L \in \mathbb{R}^d

Key characteristic: each z_\ell depends on the whole input. That is, z_\ell depends on \{w_1, \ldots, w_L\} for all \ell \in [L].

Extract global features for downstream tasks (trained separately using these features):

  • Token-level: part-of-speech classification
  • Sentence-level: sentiment analysis

Key examples: BERT, Vision Transformer (ViT)

18.3.2 Task Type 2: Decoder-Only (Autoregressive Generation)

Definition 18.3 (Decoder-Only Transformer) A decoder-only transformer generates a sequence of features for generating the next token.

  • Input: sequence of tokens w_1, w_2, \ldots, w_L
  • Output: sequence of features z_1, z_2, \ldots, z_L

Key characteristics:

  • Each z_\ell only depends on w_1, w_2, \ldots, w_\ell (autoregressive / cannot look into the future)
  • Predict w_{\ell+1} using z_\ell only, via a softmax prediction layer

Key examples: GPT family, LLaMA, Mistral

Example 18.1 (Autoregressive Generation) We want a model that predicts the next word given context. For “I am a Yale ?”, we want: \mathbb{P}(w_5 \mid w_{1:4}) = \mathbb{P}(\text{"student"} \mid \text{"I am a Yale"}).

An autoregressive LLM = Decoder-only TF + Prediction Head: \mathbb{P}_\theta(w_{\ell+1} \mid w_1, \ldots, w_\ell).

Autoregressive generation proceeds step by step:

  • \mathbb{P}(\text{"I"} \mid \text{prompt} = \text{"My name is X."})
  • \mathbb{P}(\text{"am"} \mid \text{prompt} = \text{"My name is X. I"})
  • \mathbb{P}(\text{"a"} \mid \text{prompt} = \text{"My name is X. I am"})
  • \mathbb{P}(\text{"Yale"} \mid \text{prompt} = \text{"My name is X. I am a"})
  • \mathbb{P}(\text{"student"} \mid \text{prompt} = \text{"My name is X. I am a Yale"})

Each output word is copied back into the input for the next prediction.

18.3.3 Task Type 3: Encoder-Decoder Transformer

Definition 18.4 (Encoder-Decoder Transformer) The original Transformer model (Vaswani et al., 2017). Used for machine translation and conditional generation.

The encoder processes the input sequence into features; the decoder autoregressively generates the output, attending to the encoder features via cross attention.

Example: (“Hello”, “world”, “!”) \to Encoder \to features \to Decoder \to (“Bonjour”, “le”, “monde”, “!”)

TipRemark: Current Landscape

Encoder-decoder models and encoder-only LLMs are not popular now.

  • Decoder-only models are most popular — GPT family, LLaMA, Mistral
  • Decoder-only models can also perform discriminative tasks
  • Only exception: Vision Transformer (ViT), which is encoder-only

18.4 3. Architectures of Transformers

Note: This is the most important part of this class, and it is very complicated.

There are many components of these neural networks. To introduce the architecture, we equivalently introduce the “forward” function: How is the input language token sequence transformed into the output?

Mental Picture (using GPT-3 as reference):

  • V = vocabulary size = 50,257
  • d = model dimension = 12,288
  • L = sequence length = 2,048

Input: w_1, \ldots, w_L (tokens, w_i \in \mathbb{R}^V one-hot). Transformer (embedding, MLP, attention, layer norm, residual link) produces features z_1, \ldots, z_L \in \mathbb{R}^d. Then a prediction layer produces the loss \ell_1, \ldots, \ell_L.

18.4.1 Prediction Head & Softmax

The prediction head is designed according to the task, which determines the loss function. A transformer outputs a real-valued vector z_\ell \in \mathbb{R}^d at each position, but for next-token prediction we need a probability distribution over the vocabulary. The softmax function bridges this gap by converting an arbitrary vector of real numbers (“logits”) into a valid probability distribution.

Definition 18.5 (Softmax Function) For any N real numbers \{v_i\}_{i \in [N]}, the softmax function gives us a probability distribution over [N] = \{1, \ldots, N\}: \text{Denote: } p = \text{Softmax}(\{v_i\}_{i \in [N]}) \in \mathbb{R}^N. \mathbb{P}(\text{random variable} = i) = p(i) = \frac{\exp(v_i)}{\sum_{j=1}^{N} \exp(v_j)}.

Equivalently, p(i) \propto \exp(v_i). Key insight: Softmax gives us a distribution.

The softmax function converts a vector of arbitrary real-valued scores (logits) into a valid probability distribution. The exponential function ensures all outputs are positive, and the normalization ensures they sum to one. Larger logits receive exponentially more probability mass, making softmax a “soft” version of the argmax operation.

TipRemark: Decoding (Unembedding) + Softmax

The TF produces a vector z_\ell \in \mathbb{R}^d. We can map z_\ell to \mathbb{R}^N, then apply softmax: \underbrace{W_U}_{\mathbb{R}^{N \times d}} \cdot z_\ell = \mathbb{R}^N \xrightarrow{\text{Softmax}} \text{distribution over } [N], \quad \text{e.g., over tokens with } N = V.

This is a softmax linear model.

Discriminative task: e.g., sentiment analysis — aggregate z_1, \ldots, z_L (e.g., z = \frac{1}{L}\sum_{\ell=1}^{L} z_\ell), then feed into a softmax linear classifier: \mathbb{P}(\text{positive} \mid z) \propto \exp(w^\top z).

Autoregressive generation: use z_\ell to predict w_{\ell+1} via softmax linear classification.

18.4.2 Loss Function for Decoder-Only Model

With the softmax prediction head in place, we need a loss function to train the model. The natural choice for next-token prediction is to maximize the probability of the correct next token at each position, which leads to the cross-entropy loss. This is equivalent to maximum likelihood estimation and is the standard training objective for all autoregressive language models.

Theorem 18.1 (Cross-Entropy Loss (Equivalent to MLE)) At each token position \ell \in [L], TF outputs z_\ell \in \mathbb{R}^d. After unembedding (W_U \in \mathbb{R}^{d \times V}) + softmax, we have a distribution p_\ell \in \Delta_L.

The next-token label is w_{\ell+1} (one-hot vector). The loss is: \text{Loss}(\theta) = -\sum_{\ell=1}^{L-1} w_{\ell+1}^\top \log p_\ell = -\sum_{\ell=1}^{L-1} \log \mathbb{P}_\theta(w_{\ell+1} \mid w_1, \ldots, w_\ell).

This is the cross-entropy loss, equivalent to maximum likelihood estimation (MLE). Parameters \theta are trained via gradient-based optimization using backpropagation (see Part 2 for backpropagation and automatic differentiation).

The cross-entropy loss penalizes the model for assigning low probability to the correct next token. Minimizing this loss is equivalent to maximizing the likelihood of the training data, which connects transformer training directly to the statistical framework of maximum likelihood estimation studied throughout this course.

18.4.3 Token Embedding

Definition 18.6 (Word/Token Embedding) Each word w (a one-hot vector in \mathbb{R}^N) is associated with a vector x_w \in \mathbb{R}^d via an embedding matrix W_E \in \mathbb{R}^{d \times N}: x_i = W_E \, w_i \in \mathbb{R}^d.

The embedding matrix is learned from data. Input size: L \times N. Output size: L \times d.

For GPT-3: L = 2048, N = 50{,}257, d = 12{,}288.

The embedding matrix converts discrete tokens (represented as sparse one-hot vectors in a very high-dimensional space \mathbb{R}^N) into dense, continuous vectors in a much lower-dimensional space \mathbb{R}^d. This is essential because all subsequent operations in the transformer — attention, MLP layers, optimization — operate on continuous vectors.

TipRemark: Why Word Embedding?

Word embeddings equip words with “distance” to capture similarity. Using cosine similarity: \cos(u, v) = \frac{u^\top v}{\|u\| \cdot \|v\|}.

Similar words are close in the embedded space. Word2Vec and GloVe encode semantic meaning — interesting patterns emerge (e.g., king - man + woman \approx queen). Now we are in Euclidean space and it is easy to operate using calculus.

18.5 4. Attention Mechanism

Attention treats each word’s representation as a query to access and incorporate information from a set of values.

Definition 18.7 (Attention) Given a set of vector values and a vector query, attention is a technique to compute a weighted sum of the values, dependent on the query. We say the query attends to the values.

Attention is just a weighted average — this is very powerful if the weights are learned!

In attention, the query matches all keys softly (weights between 0 and 1). In a lookup table, the query matches one key exactly.

The power of attention lies in its ability to dynamically route information: each token can selectively focus on the most relevant parts of the input, with the relevance weights learned from data. This is what allows transformers to capture long-range dependencies in sequences.

18.5.1 Cross Attention: The Equations

We now formalize the attention computation. The key idea is to use dot products between the query and each key to compute similarity scores, apply softmax to obtain weights, and then return the weighted sum of values. The 1/\sqrt{d_1} scaling factor prevents the dot products from growing too large in high dimensions, which would push softmax into regions of near-zero gradient.

Theorem 18.2 (Cross Attention Formula) Suppose we have (key, value) pairs \{(k_i, v_i)\}_{i \in [L]} with k_i \in \mathbb{R}^{d_1}, v_i \in \mathbb{R}^{d'}, and a query q \in \mathbb{R}^{d_1}.

  1. Compute similarity scores: e = (q^\top k_1, \ldots, q^\top k_L) \in \mathbb{R}^L
  2. Similarity (attention weights): \alpha = \text{Softmax}(e) \in \Delta_L, where \alpha_i = \frac{\exp(k_i^\top q / \sqrt{d_1})}{\sum_{j=1}^{L} \exp(k_j^\top q / \sqrt{d_1})}. So \alpha_i = \mathbb{P}(k_i \text{ is closest to } q).
  3. Aggregation: h = \sum_{i=1}^{L} \alpha_i \cdot v_i \in \mathbb{R}^{d'}

Output: (q, h) where q \in \mathbb{R}^{d_1}, h \in \mathbb{R}^{d'}.

TipRemark

Similarity is captured by k_i^\top q. The vector (k_1^\top q, \ldots, k_L^\top q) is called the attention score. We can use other functions in addition to softmax (e.g., ReLU).

An important structural property of the attention mechanism has a direct consequence for how we must handle sequential data.

Corollary 18.1 (Permutation Invariance) The attention output \sum_{i=1}^{L} \alpha_i \cdot v_i remains the same if we permute key-value pairs \{(k_i, v_i)\}_{i \in [L]}, because of the “\sum”.

Note: Ordering in a sequence matters. Natural language has order: “united states” \neq “states united”. We will address this with positional embeddings.

Permutation invariance is both a strength and a limitation. It means attention treats the input as a set rather than a sequence, which is why positional embeddings are essential for tasks where order matters, such as language modeling.

18.5.2 Self-Attention

Figure 18.1 illustrates the computation flow. The input matrix X \in \mathbb{R}^{L \times d} is projected through three learned weight matrices to produce queries Q, keys K, and values V. Queries and keys are combined via the scaled dot product QK^\top / \sqrt{d_k} to form a raw attention-score matrix (one row per query token, one column per key token). The softmax normalizes each row into a probability distribution over positions, and the resulting attention weights are multiplied by V to produce the final output — a context-enriched representation where each token’s output is a weighted mixture of all value vectors.

In cross attention, the queries and key-value pairs come from different sources (e.g., the decoder queries the encoder). In a transformer’s main computation, however, each token in the sequence attends to all other tokens in the same sequence. This is called self-attention, and it is the mechanism that allows each token’s representation to incorporate contextual information from the entire input.

Definition 18.8 (Self-Attention) Self-attention is an attention module where query, key, value are all computed from the same input vectors. Given post-embedding sequence X = (x_1, \ldots, x_L) \in \mathbb{R}^{L \times d}: Q = X W_Q, \quad K = X W_K, \quad V = X W_V \quad \in \mathbb{R}^{L \times d_1},

where W_Q, W_K, W_V \in \mathbb{R}^{d \times d_1} are learnable weight matrices.

For position \ell: \alpha_\ell = \text{Softmax}\!\left(\left\{q_\ell^\top k_j / \sqrt{d_1}\right\}_{j \in [L]}\right) \in \Delta_L.

The output at position \ell is: h_\ell = \sum_{j=1}^{L} \alpha_{\ell j} \cdot v_j = \sum_{j=1}^{L} \alpha_{\ell j} \cdot (W_V x_j).

Here \alpha_{\ell,j} measures the similarity between \{x_\ell, x_j\}: \alpha_{\ell j} = \frac{\exp(q_\ell^\top k_j / \sqrt{d_1})}{\sum_{s=1}^{L} \exp(q_\ell^\top k_s / \sqrt{d_1})} = \frac{\exp(x_\ell^\top W_Q^\top W_K x_j / \sqrt{d_1})}{\sum_{s=1}^{L} \exp(x_\ell^\top W_Q^\top W_K x_s / \sqrt{d_1})}.

ImportantAlgorithm: Self-Attention in Matrix Form

Input: X \in \mathbb{R}^{L \times d}, X = (x_1, x_2, \ldots, x_L).

  1. Map into queries, keys, values: Q = X W_Q, K = X W_K, V = X W_V \in \mathbb{R}^{L \times d_1}
  2. Calculate attention score: E = Q K^\top \in \mathbb{R}^{L \times L}
  3. Apply softmax to each row: P = \text{Softmax}(E / \sqrt{d_1}) \in \mathbb{R}^{L \times L}
  4. Output = PV = \text{Softmax}(Q K^\top / \sqrt{d_1}) \cdot V

Figure 12.1: Attention weight matrix visualization. Each row shows how much each token attends to every other token. Brighter cells indicate stronger attention.

18.6 5. Position Embedding

We want to include token position in the input. Since self-attention is permutation invariant, we need to explicitly encode order.

Definition 18.9 (Positional Embedding) A special trick of transformers: the embedding of (token, position) is additive: \text{emb}(\text{token}, \text{position}) = \text{emb}(\text{token}) + \text{emb}(\text{position}).

So x_i = \text{emb}(w_i) + \text{pe}_i \in \mathbb{R}^d, where d = dimension of word embedding.

The additive structure of positional embedding is a design choice that keeps the architecture simple: the model receives a single vector per token that encodes both what the token is and where it appears in the sequence. This allows the attention mechanism to use position information when computing relevance scores.

Three major practices of position embedding:

  1. Absolute embedding: each \ell \mapsto \text{pe}_\ell, trained directly. Parameters: \{\text{pe}_1, \ldots, \text{pe}_L\} \in \mathbb{R}^{L \times d}.
  2. Sinusoidal positional encoding (a special case of 3): use a fixed vector \vec{p}_t = \begin{pmatrix} \sin(\omega_1 \cdot t) \\ \cos(\omega_1 \cdot t) \\ \sin(\omega_2 \cdot t) \\ \cos(\omega_2 \cdot t) \\ \vdots \\ \sin(\omega_{d/2} \cdot t) \\ \cos(\omega_{d/2} \cdot t) \end{pmatrix}_{d \times 1}. This encodes relative positional information via rotation matrices.
  3. Relative positional embedding: embed relative positions i - j. Map (i,j) \mapsto \vec{P}_{i-j} with learnable vectors. Used in RoPE (Rotary Position Embedding, used in LLaMA). The attention score formula becomes: \alpha_i = \text{Softmax}\!\left(\{q_i^\top(k_j + \vec{P}_{i-j})\}_{j \in [L]}\right).

Figure 12.2: Sinusoidal positional encoding heatmap. Each row is a position, each column a dimension of the encoding vector. Low-frequency sinusoids vary slowly across positions while high-frequency ones oscillate rapidly.

18.7 6. Causal Masking: Don’t See the Future

For autoregressive generation, the model must predict token w_{\ell+1} using only w_1, \ldots, w_\ell. But standard self-attention lets every token attend to every other token, including future ones. Causal masking enforces the autoregressive constraint by preventing information from flowing backward in time.

Definition 18.10 (Causal Masking) In decoder-only models, we need to ensure that token \ell cannot attend to future tokens. We manually set \alpha_{\ell j} = 0 for all j > \ell.

To achieve this:

  • If j > \ell: set \text{Mask}_{\ell j} = -\infty
  • If j \leq \ell: set \text{Mask}_{\ell j} = 0

\text{Attention score} = \text{Softmax}(Q K^\top + \text{Mask}).

After softmax, the -\infty elements become zero.

Note: Only use causal masking for decoder TF. Encoder-only models (like BERT) use full (global) attention.

Causal masking enforces the autoregressive property at the architectural level: by preventing each token from attending to future positions, we ensure that the prediction of w_{\ell+1} depends only on w_1, \ldots, w_\ell. This is what makes left-to-right text generation possible during inference.

Figure 12.3: Left — Global (encoder) attention mask: all tokens attend to all tokens. Right — Causal (decoder) attention mask: each token only attends to itself and previous tokens.

18.8 7. Add MLP Layers After Each Attention Layer

Self-attention output \sum_{j=1}^{L} \alpha_{\ell j} \cdot W_V x_j is a weighted average of linear functions of embeddings. We need to add nonlinearities.

Definition 18.11 (MLP / Feed-Forward Layer) The MLP is a 2-layer neural network applied independently for each position \ell \in [L]: m_\ell = \text{MLP}(\text{output}_\ell) : \mathbb{R}^{d_1} \to \mathbb{R}^{d_1} = W_2 \cdot \sigma(W_1 x + b_1) + b_2,

where \sigma is a nonlinearity (ReLU or GELU), W_1 \in \mathbb{R}^{d_1 \times d_f}, b_1 \in \mathbb{R}^{d_f}, W_2 \in \mathbb{R}^{d_f \times d_1}, b_2 \in \mathbb{R}^{d_1}.

Typically d_f \gg d_1. In GPT-3: d_f = 4d.

The same MLP is applied independently for each \ell \in [L].

18.9 8. Multi-Head Attention

Instead of having a single attention module, we use multi-head self attention: multiple (H) attention heads in parallel.

Definition 18.12 (Multi-Head Attention) H = number of attention heads. Each head has three matrices \{W_K^h, W_Q^h, W_V^h\}_{h \in [H]}, each \in \mathbb{R}^{d \times d_1}, where d_1 = d / H.

At each position \ell, input x_\ell \in \mathbb{R}^d, d = H \cdot d_1:

  • Head h looks at x_\ell^{(h)} \in \mathbb{R}^{d_1} (the h-th chunk of the vector)
  • \text{Output}^h = \sum_{j=1}^{L} \alpha_{\ell j}^h \cdot v_j^h for each head h
  • Final output = W_O \begin{pmatrix} \text{output}^1 \\ \text{output}^2 \\ \vdots \\ \text{output}^H \end{pmatrix} \in \mathbb{R}^d, where W_O \in \mathbb{R}^{d \times d} is the output matrix that mixes across heads.
TipRemark: Each Head Captures Different Semantics

Different attention heads learn to attend to different patterns: some heads focus on adjacent tokens, some on syntactic relationships, some on semantic similarity. This is visible when visualizing attention matrices from different heads.

18.10 9. Residual Connections & Layer Normalization

A transformer decoder stacks dozens (or even nearly a hundred) layers of attention and MLP blocks. Training such deep networks without any architectural tricks would be nearly impossible due to vanishing or exploding gradients. Two key ingredients make deep transformers trainable: residual connections and layer normalization.

Definition 18.13 (Residual Connection) Instead of X^{(i)} = \text{Layer}(X^{(i-1)}), we let: X^{(i)} = X^{(i-1)} + \text{Layer}(X^{(i-1)}).

That is: X \mapsto X + \text{MHA}(X). Add the input to the output of multi-head attention. This biases the mapping to identity, so we only have to learn “the residual.”

Residual connections are critical for training deep networks: they provide a direct gradient pathway from the output back to earlier layers, preventing the vanishing gradient problem. From an optimization perspective, they make the loss landscape smoother and easier to navigate.

Layer normalization complements residual connections by stabilizing the distribution of activations across layers. Without normalization, the scale of hidden representations can drift unpredictably as data passes through many layers, making optimization difficult.

Definition 18.14 (Layer Normalization) Normalization applied to each feature vector individually. For a vector x \in \mathbb{R}^d:

  • Mean: \mu = \frac{1}{d} \sum_{j=1}^{d} x_j
  • Standard deviation: \sigma = \sqrt{\frac{1}{d} \sum_{j=1}^{d} (x_j - \mu)^2}
  • Normalization: v = \frac{x - \mu}{\sigma + \varepsilon}, where \varepsilon is a small number to avoid numerical instability

Do this operation LayerNorm: x \mapsto v for all x in the sequence: x_1, x_2, \ldots, x_L \in \mathbb{R}^d.

Layer normalization stabilizes training by ensuring that the inputs to each sub-layer have consistent scale, regardless of the activations from previous layers. This is particularly important in deep transformers with many stacked blocks, where without normalization the magnitude of activations can grow or shrink uncontrollably.

18.11 10. Full Transformer Architecture

The Transformer Decoder is a stack of Transformer Decoder Blocks. Each Block consists of:

  1. (Masked) Multi-Head Self-Attention
  2. Add & Norm (residual connection + layer norm)
  3. Feed-Forward Network (MLP)
  4. Add & Norm

Two design choices: Post-norm (original): LN after each sub-layer. Pre-norm (more popular now): LN before each sub-layer, for better training stability.

TipRemark: Revisiting Model Types
  • Encoder-only: Do not use causal masking. In training, hide (mask) some random tokens and predict them. Example: BERT.
  • Decoder-only: Use causal masking to mask the future. Trained to predict next token. Example: GPT.
  • Encoder-Decoder: Output of encoder is fed into decoder blocks, attended by features of decoder using cross attention (at each layer). Example: T5.

18.12 Exercise: Understanding GPT-3 Parameters

GPT-3 175B: n_\text{layers} = 96, d_\text{model} = 12288, n_\text{heads} = 96, d_\text{head} = 128. Context window L = 2048, vocabulary size N = 50257. Note: d = H \times d_1.

ImportantAlgorithm: Computing the Number of Parameters
  1. Word embedding: W_E \in \mathbb{R}^{N \times d} \Rightarrow \#\text{param} = N \cdot d
  2. Position embedding: W_{PE} \in \mathbb{R}^{L \times d} \Rightarrow \#\text{param} = L \cdot d
  3. Each self-attention layer: Each W_Q^h, W_K^h, W_V^h \in \mathbb{R}^{d \times d_1} \Rightarrow \#\text{param} = 3 \times d \times d_1 \times H = 3d^2. Output matrix W_O \in \mathbb{R}^{d \times d} \Rightarrow d^2. Total MHA: 4d^2 per layer \times n_\text{layer}.
  4. MLP layer: (W_1, W_2, b_1, b_2) \Rightarrow \approx 4d \times d \times 2 = 8d^2 per layer \times n_\text{layer}.

Neglecting biases and layer norms: \#\text{param} = N \cdot d + L \cdot d + 12 \cdot d^2 \times n_\text{layer} \approx 174{,}074{,}267{,}648 \approx 174 \times 10^9 \quad (99.5\% \text{ accurate}).

18.13 Transformer Circuits & Residual Stream

We can view a Transformer as a model that processes a sequence of tokens in multiple layers. In each layer, the vector at the same position is processed by attention, normalization, and MLP. The vector itself is added directly to the next layer by residual connection.

Theorem 18.3 (Single-Layer Attention-Only Transformer) For a single-layer attention-only transformer:

  • Token embedding: x_0 = W_E \, t, where t = \binom{w}{i} \in \mathbb{R}^{L+V} (token + position)
  • Attention: x_1 = x_0 + \sum_{h \in H} h(x_0)
  • Logits: T(t) = W_U x_{-1} (unembedding)

Define the QK-matrix: W_{QK}^h = (W_Q^h)^\top W_K^h / \sqrt{d} \in \mathbb{R}^{d \times d}

and the OV-matrix: W_{OV}^h = W_O^h W_V^h \in \mathbb{R}^{d \times d}.

Then: A^h = \text{Softmax}(X_0 \, W_{QK}^h \, X_0^\top) \in \mathbb{R}^{L \times L}, and we can write the full model as: T(x) = X \underbrace{(W_U W_E)^\top}_{\text{residual}} + \sum_{h=1}^{H} A^h \cdot X \cdot \underbrace{(W_U W_{OV}^h W_E)}_{\text{a single matrix}}.

where X is the input sequence, A^h = \text{Softmax}(X \, W_{QK}^h \, X^\top).

18.14.1 Self-Attention Computation

#| eval: false
import numpy as np

# Simple self-attention example
np.random.seed(42)
L = 4  # sequence length
d = 8  # embedding dimension
d1 = 4  # attention head dimension

# Simulated token embeddings (e.g., "I", "love", "deep", "learning")
tokens = ["I", "love", "deep", "learning"]
X = np.random.randn(L, d)

# Weight matrices
W_Q = np.random.randn(d, d1) * 0.3
W_K = np.random.randn(d, d1) * 0.3
W_V = np.random.randn(d, d1) * 0.3

# Compute Q, K, V
Q = X @ W_Q  # (L, d1)
K = X @ W_K
V = X @ W_V

# Attention scores
E = Q @ K.T / np.sqrt(d1)  # (L, L)
print("Raw attention scores (Q K^T / sqrt(d1)):")
print(np.round(E, 3))

# Softmax (row-wise)
def softmax(x):
    e = np.exp(x - x.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)

alpha = softmax(E)
print("\nAttention weights (after softmax):")
for i, tok in enumerate(tokens):
    weights = ", ".join(f"{tokens[j]}: {alpha[i,j]:.3f}" for j in range(L))
    print(f"  {tok} attends to -> {weights}")

# Output
output = alpha @ V
print(f"\nOutput shape: {output.shape}")
print(f"Output (first 3 dims):\n{np.round(output[:, :3], 3)}")

# Causal mask for decoder
print("\n--- With Causal Masking ---")
mask = np.triu(np.ones((L, L)) * (-1e9), k=1)
E_masked = E + mask
alpha_causal = softmax(E_masked)
print("Causal attention weights:")
for i, tok in enumerate(tokens):
    weights = ", ".join(f"{tokens[j]}: {alpha_causal[i,j]:.3f}" for j in range(L))
    print(f"  {tok} attends to -> {weights}")

Summary

  • Attention mechanism. The core operation computes \operatorname{Attention}(Q,K,V) = \operatorname{softmax}\!\bigl(\frac{QK^\top}{\sqrt{d_k}}\bigr)V, where queries, keys, and values are linear projections of the input; this allows each token to attend to all other tokens with learned, content-dependent weights.
  • Positional encoding. Since self-attention is permutation-equivariant, sinusoidal positional encodings \operatorname{PE}(pos, 2i) = \sin(pos / 10000^{2i/d}) inject sequence-order information; causal masking further enforces autoregressive structure by preventing attention to future tokens.
  • Transformer block. Each block applies multi-head self-attention followed by a position-wise MLP, with residual connections and layer normalization (x + \operatorname{Sublayer}(x)) around each sub-layer—enabling stable training of very deep models.
  • Multi-head attention. Running h attention heads in parallel with independent projections W_i^Q, W_i^K, W_i^V lets the model capture diverse relational patterns; outputs are concatenated and linearly projected back to the model dimension.
