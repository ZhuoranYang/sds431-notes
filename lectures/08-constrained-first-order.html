8  Constrained First-Order Methods

Many of the most useful functions in optimization are not differentiable everywhere. Norms, absolute values, ReLU activations, and pointwise maxima of convex functions all have “kinks” where no classical gradient exists. Yet deep learning frameworks like PyTorch happily compute gradients of these functions, and optimization algorithms converge on problems involving them. The mathematical foundation that makes this possible is the theory of subgradients — a generalization of the gradient to nonsmooth convex functions.

This chapter develops two fundamental algorithms for nonsmooth and constrained optimization. Projected subgradient descent extends gradient descent to problems where the objective is nonsmooth and the feasible region is a convex set. It is simple to implement but converges at a slower O(1/\sqrt{K}) rate, reflecting the inherent difficulty of optimizing without smoothness. The Frank-Wolfe (conditional gradient) method takes a different approach to constrained optimization: instead of projecting onto the constraint set (which can be expensive), it solves a linear minimization over the constraint set at each iteration. This makes Frank-Wolfe especially attractive when the constraint set has special structure — such as a polytope, a nuclear norm ball, or a spectrahedron — where linear minimization is cheap even though projection is not.

Together, these methods round out the first-order optimization toolkit, equipping us to handle the nonsmooth, constrained problems that arise throughout statistics, machine learning, and signal processing.

8.2 Subgradients

We begin by establishing the theoretical foundation: a precise definition of “generalized gradient” for nonsmooth convex functions and the key properties that make subgradients useful in both analysis and computation.

8.2.1 Definition

Recall: if f is convex and differentiable, then

f(y) \geq f(x) + \langle \nabla f(x),\, y - x \rangle.

Definition 8.1 (Definition 10.1 (Subgradient)) Let f be a convex function. Let D = \text{dom}(f). A subgradient of f at x is any vector g \in \mathbb{R}^n satisfying

f(y) \geq f(x) + \langle g,\, y - x \rangle \quad \forall\, y \in D.

A subgradient generalizes the notion of a gradient to nonsmooth convex functions. While a differentiable function has a unique tangent hyperplane at each point, a nonsmooth convex function may have many supporting hyperplanes at a point of nondifferentiability, and each corresponds to a different subgradient.

Definition 8.2 (Definition 10.2 (Subdifferential)) We define the set of all subgradients of f at x as the subdifferential of f at x, denoted by \partial f:

\partial f(x) = \bigl\{g \in \mathbb{R}^n : f(y) \geq f(x) + \langle g,\, y - x \rangle,\; \forall\, y \in D \bigr\}.

The subdifferential collects all subgradients at a given point into a single set. At points where f is differentiable, this set contains only the gradient. At kinks or corners, the subdifferential is a convex set that “fills in” between the one-sided derivatives.

8.2.2 Remarks

TipRemarks on Subgradients
  1. \partial f exists (nonempty) for convex f for all x \in \text{int}(D).
  2. If f is differentiable \Rightarrow \partial f(x) = \{\nabla f(x)\}.
  3. For any x \notin \text{dom}(f), define \partial f(x) = \emptyset.
  4. If \partial f(x) is a singleton, \partial f(x) = \{g\}, then f is differentiable at x and g = \nabla f(x).
  5. \partial f(x) is a closed and convex set.

Example 8.1 (Convex Function Not Subdifferentiable at Boundary) Consider

f(x) = \begin{cases} -\sqrt{x} & x \geq 0, \\ \infty & \text{otherwise.} \end{cases}

Here \text{dom}(f) = [0, \infty). At x = 0, we need f(y) - f(0) = -\sqrt{y} \geq g \cdot y for all g. But as y \to 0^+,

x = \tfrac{1}{4g^2} \;\Rightarrow\; -\sqrt{\tfrac{1}{4g^2}} \geq \tfrac{1}{4g^2} \cdot g \;\Rightarrow\; -\tfrac{1}{2g} \geq \tfrac{1}{4g},

which is impossible. Thus f is not subdifferentiable at x = 0 (a boundary point of \text{dom}(f)).

Proof (Proof that \partial f(x) is Convex). If g_1, g_2 \in \partial f(x), then

f(y) \geq f(x) + \langle g_1,\, y - x\rangle \quad \cdots (1) f(y) \geq f(x) + \langle g_2,\, y - x\rangle \quad \cdots (2)

Taking the convex combination \alpha \cdot (1) + (1 - \alpha) \cdot (2), and using the linearity of the inner product, we get:

f(y) \geq f(x) + \langle \alpha g_1 + (1-\alpha)g_2,\, y - x\rangle.

Hence \alpha g_1 + (1 - \alpha)g_2 \in \partial f(x). Since every convex combination of elements in \partial f(x) remains in \partial f(x), the subdifferential is convex. This completes the proof. \blacksquare

8.3 Examples of Subgradients

8.3.1 1. Absolute Value

Let f(x) = |x|, x \in \mathbb{R}.

\partial f(x) = \begin{cases} \{\text{sign}(x)\} & x \neq 0, \\ [-1, 1] & x = 0. \end{cases}

Figure 10.1: The absolute value function |x| and supporting lines at x=0. Every slope in [-1,1] gives a valid tangent line below the graph.

8.3.2 2. Euclidean Norm

Let f(x) = \|x\|_2, x \in \mathbb{R}^n.

  • For x \neq 0: f is differentiable. We have \frac{\partial f}{\partial x_i} = \frac{1}{2}\Bigl(\sum_{j=1}^n x_j^2\Bigr)^{-1/2} \cdot 2x_i = \frac{x_i}{\|x\|_2}, so the unique subgradient is \dfrac{x}{\|x\|_2}.
  • For x = 0: The subgradient g is any element of \bigl\{z : \|z\|_2 \leq 1\bigr\}, since z^\top x \leq \|z\|_2 \cdot \|x\|_2 by Cauchy-Schwarz.

8.3.3 3. General Norms and Dual Norms

For any norm \|\cdot\|, define its dual norm as

\|y\|_* = \sup_{\|x\| \leq 1} x^\top y.

TipRemark

Then (\partial \|\cdot\|)(x) \supseteq \{g : \|g\|_* \leq 1\}.

8.3.4 4. Pointwise Maximum of Convex Functions

Let f(x) = \max\{f_1(x),\, f_2(x)\}, where f_1, f_2 are convex.

\partial f(x) = \begin{cases} \{f_1'(x)\} & \text{if } f_1(x) > f_2(x), \\ [f_2'(x),\, f_1'(x)] & \text{if } f_1(x) = f_2(x), \\ \{f_2'(x)\} & \text{if } f_2(x) > f_1(x). \end{cases}

Figure 10.2: The function max{f₁(x), f₂(x)}. At the kink where f₁ = f₂, the subdifferential is the interval [f₂', f₁'].
TipRemark: PyTorch and Subgradients
  • PyTorch defines gradients using a subgradient. For example, \partial\,\text{ReLU}(0) = 0, \partial\|\cdot\|(0) = 0.
  • (\partial \max\{f, g\})(x) = \frac{1}{2}f'(x) + \frac{1}{2}g'(x) when f(x) = g(x). (Not exactly a subgradient, but works in practice.)
  • For minimization, use the fact that \min = -\max.

Having established the definition and basic properties of subgradients, we now develop the calculus rules that make subgradients practically useful. Just as the chain rule is the workhorse of smooth calculus, we need analogous composition and combination rules for subdifferentials.

8.4 Subgradient Calculus

Most of the familiar calculus rules for gradients carry over to subgradients, including the chain rule and composition rules. These rules allow us to compute subdifferentials of complex functions built from simpler pieces — exactly what is needed for optimality conditions and algorithm design.

8.4.1 Chain Rule

Just as the chain rule is fundamental to calculus with smooth functions, we need a chain rule for subgradients to handle compositions of nonsmooth functions. The following result shows that the familiar chain-rule structure carries over, provided the outer function is differentiable and nondecreasing.

Theorem 8.1 (Theorem 10.3 (Chain Rule for Subgradients)) Let f : \mathbb{R}^n \to \mathbb{R} be a convex function, and g : \mathbb{R} \to \mathbb{R} be a nondecreasing convex function. Suppose g is differentiable. (Note: g \circ f is convex.)

Let h = g \circ f. Then

\partial h(x) = g'(f(x)) \cdot \partial f(x).

This chain rule says that composing a convex function f with a nondecreasing differentiable convex function g preserves the subdifferential structure: we simply multiply each subgradient of f by the scalar derivative g'(f(x)).

8.4.2 Composition Rule

We often encounter functions that are compositions of multiple convex functions through a differentiable nondecreasing outer function. The following result generalizes the chain rule to this multivariate setting.

Theorem 8.2 (Theorem 10.4 (Composition)) Suppose h(x) = g(f_1(x), \ldots, f_m(x)), where f_1, \ldots, f_m are convex, g is differentiable, nondecreasing, and convex. For any given x, let

\gamma = \nabla g(y)\Big|_{y = (f_1(x), \ldots, f_m(x))^\top} \in \mathbb{R}^m.

Then

\partial h(x) = \Bigl\{\sum_{i=1}^{m} \gamma_i g_i \;\Big|\; g_i \in \partial f_i(x)\Bigr\}.

This is the analog of the standard chain rule. The standard chain rule gives

\nabla h(x) = \sum_i \frac{\partial g}{\partial y_i}(y)\Big|_{y = (f_1(x), \ldots, f_m(x))^\top} \cdot \nabla f_i(x).

Example 8.2 (Example: f(x) = \|x\|_1^2) Write f(x) = \|x\|_1^2 = \bigl(\sum_{i=1}^n |x_i|\bigr)^2. Let h(t) = t^2 and g(x) = \|x\|_1. Then

\partial f(x) = 2\|x\|_1 \cdot \partial g(x) = \bigl\{2\|x\|_1 \cdot z \;\big|\; |z_i| \leq 1 \text{ if } x_i = 0,\; z_i = \text{sign}(x_i) \text{ otherwise}\bigr\}.

8.4.3 Pointwise Maximum Rule

The pointwise maximum of convex functions arises frequently — for instance, in robust optimization and piecewise linear modeling. The subdifferential of a pointwise maximum is determined by the subdifferentials of the “active” functions, i.e., those achieving the maximum.

Theorem 8.3 (Theorem 10.5 (Pointwise Maximum)) Let f_i(x) = \max_{1 \leq i \leq k} f_i(x), where x \in \bigcap_{i=1}^k \text{int}(\text{dom}(f_i)). Then

\partial f(x) \supseteq \bigcup_{\substack{i:\, f_i(x) = f(x)}} \partial f_i(x) = \bigcup_{i \in I(x)} \partial f_i(x),

where I(x) = \{i : f_i(x) = f(x)\} is the set of active indices.

Example 8.3 (Piecewise Linear Function) Let f(x) = \max_{1 \leq i \leq m}\{a_i^\top x + b_i\}. Then I(x) = \{j : a_j^\top x + b_j = \max_i \{a_i^\top x + b_i\}\}.

For any j \in I(x), a_j \in \partial f(x). More generally,

\sum_{j \in I(x)} \lambda_j a_j \in \partial f(x) \quad \text{where } \sum_{j \in I(x)} \lambda_j = 1,\; \lambda_j \geq 0.

8.5 Optimality Conditions

Armed with subgradient calculus rules, we can now characterize when a point is optimal for nonsmooth problems, paralleling the role that \nabla f(x^*) = 0 plays in smooth optimization.

8.5.1 1. Unconstrained Case

For smooth functions, the optimality condition \nabla f(x^*) = 0 is the starting point for all optimization algorithms. For nonsmooth convex functions, the analogous condition involves the subdifferential: optimality is equivalent to the zero vector belonging to the subdifferential.

Theorem 8.4 (Theorem 10.6 (Unconstrained Optimality)) Let f : D \to \mathbb{R} be a convex function. Then

x^* \in \arg\min\{f(x) : x \in \mathbb{R}^n\} \iff 0 \in \partial f(x^*). \tag{8.1}

This is the nonsmooth analog of the familiar condition \nabla f(x^*) = 0 for smooth optimization. The zero vector must belong to the subdifferential at a minimizer, meaning there is a supporting hyperplane at x^* with zero slope.

8.5.2 2. Convex and Constrained Case

Consider the problem \min_{x} f(x) subject to x \in \mathcal{C}. When a constraint is present, the condition 0 \in \partial f(x^*) is too strong — the minimizer of f over \mathcal{C} may not be a global minimizer of f. Instead, optimality requires that no feasible direction can decrease the objective, which is captured by the following condition involving the normal cone.

Theorem 8.5 (Theorem 10.7 (Constrained Optimality)) x^* is optimal if and only if there exists g \in \partial f(x^*) such that

\langle g,\, x - x^* \rangle \geq 0 \quad \forall\, x \in \mathcal{C}. \tag{8.2}

Equivalently, -g \in N_{\mathcal{C}}(x^*), the normal cone of \mathcal{C} at x^*.

This condition says that at an optimal point x^*, the negative of some subgradient must point into the constraint set (or along its boundary). In other words, there is no feasible direction that can decrease the objective. This generalizes the KKT conditions to nonsmooth functions.

The optimality conditions above tell us when a point is optimal, but they do not tell us how to find such a point. We now turn to algorithmic methods that use subgradients as the basis for iterative optimization.

8.6 Subgradient Descent

With the optimality conditions (Equation 8.1 and Equation 8.2) in hand, we now turn to algorithms. The natural approach is to replace the gradient in gradient descent with a subgradient. Consider the unconstrained problem \min_{x} f(x) where f is convex (but possibly nonsmooth).

ImportantAlgorithm: Subgradient Descent 
For k = 0, 1, 2, ...:
    x^{k+1} = x^k - alpha^k * g^k,  where g^k in partial f(x^k).

For the constrained problem \min_{x \in \mathcal{C}} f(x), where f is convex and \mathcal{C} is a closed convex set:

ImportantAlgorithm: Projected Subgradient Descent 
For k = 0, 1, 2, ...:
    x^{k+1} = Pi_C(x^k - alpha^k * g^k),  where g^k in partial f(x^k).

8.6.1 Do Subgradients Always Give Descent Directions?

Question: Do subgradient steps always decrease the objective?

For gradient descent on smooth functions, when \alpha is sufficiently small:

f(x - \alpha \nabla f(x)) = f(x) - \alpha \|\nabla f(x)\|_2^2 + O(\alpha^2).

But are all vectors in -\partial f(x) legitimate descent directions?

No. Not all subgradient directions are descent directions. We cannot expect monotone function decrease!

Example 8.4 (Non-Descent Subgradient Direction) Let f(x) = |x_1| + 2|x_2|, x = (x_1, x_2)^\top.

At the point z = (1, 0)^\top:

\partial f(z) = \Bigl\{\begin{pmatrix}1\\t\end{pmatrix} \;\Big|\; |t| \leq 2\Bigr\}.

Case 1: g_1 = (1, 0)^\top \in \partial f(z).

f(z - t\,g_1) = f\bigl((1-t, 0)^\top\bigr) = |1-t| \leq f(z) \quad \text{for } t \in [0,1].

So -g_1 is a descent direction.

Case 2: g_2 = (1, 2)^\top \in \partial f(z).

f(z - t\,g_2) = f\bigl((1-t, -2t)^\top\bigr) = |1-t| + 4|t| = \begin{cases}1 + 2t & t \in [0,1],\\5t - 1 & t \geq 1.\end{cases}

So f(z - t\,g_2) > f(z) for all t > 0. Thus -g_2 is not a descent direction.

Figure 10.3: Function values along two subgradient directions from z = (1,0). The direction -g₁ descends, but -g₂ does not.

8.7 Convergence Theory

Since we cannot hope for monotonic decrease in \{f(x^k)\}_{k \geq 0}, we track the average error:

\frac{\sum_{k=0}^{K} \alpha^k \bigl(f(x^k) - f(x^*)\bigr)}{\sum_{k=0}^{K} \alpha^k} \;\geq\; \min_{0 \leq k \leq K}\bigl(f(x^k) - f(x^*)\bigr),

where x^* is any point in \arg\min_{x \in \mathcal{C}} f(x), and the right-hand side is the best iterate error.

Function class: We focus on Lipschitz and convex functions. The Lipschitz condition is the natural regularity assumption for nonsmooth optimization — it bounds how fast the function can change, which in turn bounds the norm of any subgradient.

Definition 8.3 (Definition 10.8 (L-Lipschitz)) f is L-Lipschitz if

|f(x) - f(x')| \leq L \|x - x'\|_2 \quad \forall\, x, x' \in \text{dom}(f).

Implication: \|g\|_2 \leq L for all g \in \partial f(x), for all x.

An L-Lipschitz function cannot change too rapidly: its function values are bounded by a linear function of the distance between points. This condition is weaker than smoothness and naturally holds for many nonsmooth functions of interest, such as norms.

With the Lipschitz condition in hand, we can now state the convergence guarantee for projected subgradient descent. Since the method does not guarantee monotone decrease in the objective (as shown in the example above), the convergence is measured in terms of the best iterate seen so far.

Theorem 8.6 (Theorem 10.9 (Convergence of Projected Subgradient Descent)) Consider (projected) subgradient descent with stepsizes \{\alpha^k\}_{k \geq 0} on an L-Lipschitz convex f. Then

\min_{0 \leq k \leq K}\bigl\{f(x^k) - f^*\bigr\} \;\leq\; \underbrace{\frac{\sum_{k=0}^{K} \alpha^k \bigl(f(x^k) - f^*\bigr)}{\sum_{k=0}^{K} \alpha^k}}_{\text{Err}_{\text{ave}}} \;\leq\; \frac{\|x^0 - x^*\|_2^2 + L^2 \sum_{k=0}^{K}(\alpha^k)^2}{2\sum_{k=0}^{K}\alpha^k}. \tag{8.3}

This theorem provides a convergence guarantee for projected subgradient descent without requiring monotone decrease in the objective. The bound shows that the best iterate among all K steps achieves an error controlled by the ratio of cumulative squared step sizes to cumulative step sizes, revealing the fundamental tension in choosing step sizes for nonsmooth optimization.

TipRemark: Step Size Conditions

This result holds for all step size sequences \{\alpha^k\}. We want:

  • \sum \alpha^k \to \infty (so the denominator grows).
  • \sum (\alpha^k)^2 = \widetilde{O}(1) (grows at most polylogarithmically in k).

Optimal choice: \alpha^k = \frac{1}{\sqrt{k}}. Then

\text{Err}_{\text{best}} \;\leq\; \text{const} \cdot \frac{\|x^0 - x^*\|_2^2 + L^2 \log K}{\sqrt{K}} \;=\; \widetilde{O}\!\left(\frac{1}{\sqrt{K}}\right).

Projected subgradient descent gives us a general-purpose tool for constrained nonsmooth optimization, but its reliance on projection can be a computational bottleneck. For many structured constraint sets, computing the projection is itself a difficult optimization problem. This motivates an entirely different approach to constrained optimization.

8.8 Frank-Wolfe (Conditional Gradient)

Projected subgradient descent achieves a convergence rate of \widetilde{O}(1/\sqrt{K}) (Equation 8.3), but it requires projecting onto the constraint set \mathcal{C} at each iteration. For many structured constraint sets (polytopes, nuclear norm balls, spectrahedra), projection is computationally expensive. The Frank-Wolfe method avoids projection entirely by instead solving a linear minimization over \mathcal{C}.

Setup: Constrained optimization

\min_{x \in \mathcal{C}} f(x),

where \mathcal{C} is a convex set and f is differentiable.

8.8.1 Algorithm

ImportantAlgorithm: Frank-Wolfe (Conditional Gradient) 
For k = 1, 2, ..., K:
    y^k = argmin_{y in C} <grad f(x^k), y>     // Find steepest descent direction in C
    x^{k+1} = (1 - alpha^k) x^k + alpha^k y^k  // Convex combination (average)

8.8.2 Fixed Point Interpretation

Why is this reasonable? Suppose x^k = x^* (optimal). Then x^* = y^k \Rightarrow x^{k+1} = x^*. That is, x^* is a fixed point of Frank-Wolfe.

To see this: by first-order optimality, \langle \nabla f(x^*),\, y - x^* \rangle \geq 0 for all y \in \mathcal{C}. Thus \langle \nabla f(x^*),\, y \rangle \geq \langle \nabla f(x^*),\, x^* \rangle for all y \in \mathcal{C}, which implies

\arg\min_{y \in \mathcal{C}} \langle \nabla f(x^*),\, y \rangle = x^*.

Another interpretation of the Frank-Wolfe descent direction:

y^k = \arg\min_{v \in \mathcal{C}} \bigl\{\underbrace{f(x^k) + \langle \nabla f(x^k),\, v - x^k \rangle}_{\text{linear surrogate of } f(v)}\bigr\}.

Figure 10.4: Frank-Wolfe iteration: linearize f at x^k, minimize the linear surrogate over C to get y^k, then take a convex combination step.

8.8.3 Convergence

Frank-Wolfe converges at a sublinear rate that depends on the smoothness of f (through the Hessian bound L) and the “size” of the constraint set (through its diameter d_{\mathcal{C}}). The convergence is O(1/K), which is faster than the O(1/\sqrt{K}) rate of projected subgradient descent, but only applies when f is smooth.

Theorem 8.7 (Theorem 10.10 (Frank-Wolfe Convergence)) Let d_{\mathcal{C}} = \sup_{x, y \in \mathcal{C}} \|x - y\| be the diameter of \mathcal{C}. Set \alpha^k = \frac{2}{k+2} for k \geq 0.

When \nabla^2 f is bounded in the sense that \lambda_{\max}(\nabla^2 f(x)) \leq L, then

f(x^K) - f(x^*) \;\leq\; \frac{2L\,d_{\mathcal{C}}^2}{K + 2}. \tag{8.4}

The Frank-Wolfe method converges at a rate of O(1/K) (Equation 8.4), which is faster than the O(1/\sqrt{K}) rate of subgradient methods (Equation 8.3). The key advantage is that Frank-Wolfe only requires solving a linear optimization problem over \mathcal{C} at each step (rather than a projection), which can be much cheaper for structured constraint sets such as polytopes or nuclear norm balls.

TipRemarks on Frank-Wolfe
  • Even when f is strongly convex, we cannot achieve linear convergence with Frank-Wolfe.
  • Frank-Wolfe can be applied beyond convex functions.

8.8.4 Nonconvex Example: Leading Eigenvector

Consider the nonconvex problem (with \mathbf{Q} \succ 0):

\min_{x} \;-x^\top \mathbf{Q}\,x \quad \text{s.t.} \quad \|x\|_2 \leq 1.

The solution is f^* = -\lambda_{\max}(\mathbf{Q}) and x^* is the leading eigenvector.

The Frank-Wolfe linear subproblem becomes:

y^k = \arg\min_{\|v\|_2 \leq 1} \langle -2\mathbf{Q}x^k,\, v\rangle = \frac{\mathbf{Q}x^k}{\|\mathbf{Q}x^k\|_2}.

The update becomes:

x^{k+1} = (1 - \alpha^k)\,x^k + \alpha^k \cdot \frac{\mathbf{Q}x^k}{\|\mathbf{Q}x^k\|_2}.

TipRemark: Connection to Power Iteration

If we set \alpha^k = 1, then x^{k+1} = \frac{\mathbf{Q}x^k}{\|\mathbf{Q}x^k\|_2}, which is exactly power iteration.

Even when \alpha^k \neq 1, Frank-Wolfe still finds the leading eigenvector.

Figure 10.5: Convergence comparison — projected subgradient descent (O(1/√K)) vs. Frank-Wolfe (O(1/K)) on representative problems.

With projected subgradient descent and the Frank-Wolfe method in hand, we have completed the first-order optimization toolkit for nonsmooth and constrained problems. The choice between these methods depends on the problem structure: projected subgradient descent is simple and broadly applicable but converges slowly at O(1/\sqrt{K}); Frank-Wolfe avoids projections entirely and converges at O(1/K) for smooth objectives, making it the method of choice when linear minimization over the constraint set is cheap.

Summary

  • Subgradients generalize gradients. For a convex (possibly non-smooth) function f, a vector g is a subgradient at x if f(y) \geq f(x) + g^\top(y - x) for all y; the set of all subgradients is the subdifferential \partial f(x). Optimality holds if and only if 0 \in \partial f(x).
  • Projected subgradient descent. For constrained non-smooth problems \min_{x \in C} f(x), the update x^{k+1} = \Pi_C(x^k - \alpha^k g^k) projects back onto the feasible set after each subgradient step; with diminishing step sizes, convergence is O(1/\sqrt{K}).
  • Frank-Wolfe (conditional gradient) method. Instead of projecting, Frank-Wolfe linearizes the objective and solves \min_{s \in C} \nabla f(x^k)^\top s at each step, then moves toward the minimizer. This avoids projections entirely—a major advantage when projection is expensive but linear optimization over C is cheap.
  • Convergence comparison. Projected subgradient descent achieves O(1/\sqrt{K}) for non-smooth problems; Frank-Wolfe achieves O(1/K) for smooth problems over compact sets, with iterates that are sparse convex combinations of vertices of C.
